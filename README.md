# Italy AI Cultural Tourism Revenue Assistant

Android prototype in English based on the thesis idea: Artificial Intelligence in Cultural Tourism Marketing, Enhancing Revenue Management Strategies for Made in Italy Experiences.

## Main features
- Cultural experiences catalog
- AI-style recommendation engine
- Visitor profile inputs
- Dynamic pricing simulator
- Revenue dashboard and managerial insights

## How to open
1. Open Android Studio.
2. Choose **Open** and select this project folder.
3. Let Gradle sync.
4. Run the app on an emulator or Android phone.

## Tech stack
- Kotlin
- Jetpack Compose
- Material 3
- Android Gradle Plugin 8.7.3
